# 证据卡：直觉判断的系统性缺陷
- 来源：《思考，快与慢》（丹尼尔·卡尼曼）
- 域：心理
- 类型：书籍

卡尼曼提出人类思维有双系统：系统一快速直觉、系统二缓慢理性。直觉判断在陌生复杂领域会系统性地过度自信，产生可得性偏差与锚定效应——人们高估易想起的例证、被初始数字锚定。这支持"在重大决策上保持审视"的立场：直觉擅长熟悉的低风险场景，但在高风险新领域，未经校验的直觉不可靠。

# 证据卡：群体匿名与责任稀释
- 来源：《乌合之众》（古斯塔夫·勒庞）
- 域：社会
- 类型：书籍

勒庞指出个体融入群体后会出现匿名导致的责任感稀释：约束个人的道德与责任机制在群体中被削弱，情绪更易传染、观点更易极端化。匿名环境既释放了表达的活力，也放大了攻击性与非理性——治理群体行为需要可追溯的责任框架与之平衡。

# 证据卡：技术是自体的组合进化
- 来源：《技术的本质》（布莱恩·阿瑟）
- 域：科技
- 类型：书籍

阿瑟认为新技术源于已有技术的组合与递归：所有技术都站在前代技术的肩膀上，依赖链条本身就是文明的构成方式。火、电、互联网的采纳史表明，深度依赖技术并非失控，而是技术生态的正常代谢——关键是保留对关键环节的治理能力。

# 证据卡：信息茧房与群体极化
- 来源：《信息乌托邦》（凯斯·桑斯坦）
- 域：社会
- 类型：书籍

桑斯坦的研究表明：当人们只在同质圈层内获取信息时，观点会向极端方向极化；异质信息的接触能显著缓和这一趋势。匿名与算法分发若加剧同质化，公共讨论质量会下降——这为"表达环境需要多元与制衡机制"提供了经典论据。

# 证据卡：大规模协作依赖共同虚构
- 来源：《人类简史》（尤瓦尔·赫拉利）
- 域：社会
- 类型：书籍

赫拉利提出"虚构故事"是人类大规模协作的基础：货币、公司、法律都是被集体相信的想象物。人类的力量不在于个体理性，而在于围绕共同叙事组织起来的能力。对"工具/制度扩展人类能力"的一方，这是能力延伸而非退化的历史证据。

# 证据卡：颠覆式创新始于边缘
- 来源：《创新者的窘境》（克莱顿·克里斯坦森）
- 域：商业
- 类型：书籍

克里斯坦森发现成熟组织往往因聚焦主流客户而被边缘创新颠覆：新技术的早期形态粗糙、性能不足，但在利基市场迭代后反超 incumbent。"不完美但快速迭代"战胜"完美但迟缓"，是支持快速试错、拥抱不成熟技术的经典管理学论据。

# 证据卡：数据提取的监控逻辑
- 来源：《监控资本主义时代》（肖莎娜·祖博夫）
- 域：科技
- 类型：书籍

祖博夫提出"监控资本主义"概念：平台经济的行为剩余价值提取，将用户体验转为可预测、可出售的商品。当依赖成为默认，个体议价能力与退出选项被系统性侵蚀——这为"依赖需要警惕与制度制衡"提供了有力的批判视角。

# 证据卡：细节是系统的可观测面
- 来源：《精益创业》（埃里克·莱斯）
- 域：商业
- 类型：书籍

莱斯主张以最小可行产品快速验证假设：资源应集中于"经证实的认知"而非大而全的完美计划。对成败起决定作用的往往是最早被验证或证伪的那个关键假设——抓大放小不等于忽视关键细节，而是区分"关键路径"与"噪声"。

# 证据卡：社会资本与实名信任
- 来源：《信任：社会美德与创造经济繁荣》（弗朗西斯·福山）
- 域：社会
- 类型：书籍

福山论证高信任度社会中，普遍信任（对陌生人的信任）显著降低交易成本、支撑大型组织与市场经济。信任是缓慢积累、快速崩塌的公共品；身份可信机制（含可追溯的责任体系）是普遍信任的基础设施之一。

# 证据卡：技能退化在工具史中反复出现
- 来源：《技术垄断》（尼尔·波斯曼）
- 域：科技
- 类型：书籍

波斯曼指出每一次技术垄断都伴随被替代技能的退化：文字记载削弱记忆、计算器削弱心算、导航削弱空间认知。技术给什么，同时也拿走什么——对"能力退化"一方，这是批判性审视技术依赖的经典人文主义证据。

# 证据卡：要事第一与精力的稀缺性
- 来源：《高效能人士的七个习惯》（史蒂芬·柯维）
- 域：通用
- 类型：书籍

柯维提出"要事第一"：人的时间与注意力是有限资源，成大事者必须区分重要与紧急，把主要精力投给决定性的大事，而非面面俱到地困于琐碎小节。效能来自对次要事务的主动舍弃——抓大放小、不拘小节不是粗疏，而是资源最优配置的必然选择；只要守住原则底线，琐事上的取舍正是成大事者的标志。

# 证据卡：瑞士奶酪模型与小疏漏的穿透
- 来源：《组织事故风险管理》（詹姆斯·瑞森）
- 域：通用
- 类型：理论

瑞森的瑞士奶酪模型指出：重大事故极少源于单一巨大失误，而是多道防线上的小疏漏层层穿透的结果——每一片被忽视的小节都是奶酪上的一片孔洞。当成大事者轻视小节，孔洞对齐之时，大事业恰恰在细节失守处崩塌。拘小节不是面面俱到的内耗，而是守住关键细节与原则的防线管理。
