# 证据卡：安全基地与依恋类型
- 来源：《依恋》（约翰·鲍尔比）/ 安斯沃斯陌生情境实验
- 类型：文献
- 域：情感

依恋理论指出，婴幼儿与照料者的互动形成安全型、焦虑型、回避型等依恋模式，并延续至成年亲密关系。安全型依恋者相信自己值得被爱、他人可信赖，更敢于探索世界；焦虑型则持续寻求确认。被爱的稳定体验有助于形成安全基地——但依恋模式也可通过主动经营与新的关系经验修复，并非开局注定。

# 证据卡：亲密关系的系统科学
- 来源：《亲密关系》（罗兰·米勒）
- 类型：书籍
- 域：情感

米勒综合关系科学研究：关系的满意度取决于双方互动质量而非单方付出强度；"得到的爱"与"给予的爱"共同塑造关系体验。研究还表明相互性是长期关系的强预测因子——纯粹单向的付出或接受都难以维持高满意度，这提示两种开局选择都需走向双向。

# 证据卡：爱是一种需要学习的能力
- 来源：《爱的艺术》（埃里希·弗洛姆）
- 类型：书籍
- 域：情感

弗洛姆主张爱不是坠入的状态而是需要习得的艺术：关心、责任、尊重、了解四要素缺一不可。人们常把"被爱"当作运气、把"爱"当作本能，实则两者都需要主动实践。该观点支持"主动去爱是能力而非冲动"，也提醒"被爱开局"若缺乏主动回应同样会枯萎。

# 证据卡：爱情三角理论
- 来源：罗伯特·斯坦伯格爱情三角理论
- 类型：文献
- 域：情感

斯坦伯格提出爱情由激情、亲密、承诺三要素构成：激情来得最快也消退最快，亲密与承诺需要时间建构。仅有一方爱意的开局在激情维度占优，但若亲密与承诺能随后共建，关系同样可走向完满——三要素的动态发展比开局状态更具解释力。

# 证据卡：熟悉催生喜欢
- 来源：曝光效应（罗伯特·扎荣茨实验研究）
- 类型：文献
- 域：情感

扎荣茨的系列实验表明：重复暴露会提升人对刺激对象的喜欢程度（曝光效应），前提是初始态度非负。这为"先被爱、后培养感情"的路径提供了心理学支持——初始好感存在时，相处与了解会加深情感。但若初始印象为负，曝光反而加剧厌恶，说明被爱开局并非无条件占优。

# 证据卡：自我扩张理论
- 来源：自我扩张理论（阿瑟·阿伦）
- 类型：文献
- 域：情感

阿伦提出人具有扩张自我概念的根本动机，亲密关系是重要途径：与所爱之人结合能纳入对方的资源、视角与经验，带来兴奋与成长感。主动去爱所伴随的自我扩张体验，是"选我爱的人"幸福感的重要来源；但该理论同样强调相互性——单方面扩张难以持续。

# 证据卡：婚姻稳定性的实证研究
- 来源：《幸福的婚姻》（约翰·戈特曼）
- 类型：书籍
- 域：情感

戈特曼基于长期观察提出"婚姻末日四骑士"（批评、鄙视、防卫、筑墙）等可预测关系破裂的行为模式，修复尝试的有效性比冲突多少更决定关系存续。关系的成败更多取决于双方如何处理分歧与修复连接，而非开局时谁更爱谁——两种开局都绕不开这项长期功课。

# 证据卡：激情之爱的时限
- 来源：激情之爱研究（多萝西·坦诺夫《爱与被爱》等）
- 类型：文献
- 域：情感

坦诺夫对激情之爱（limerence）的研究显示：强烈的迷恋状态通常有明确时限，且高度依赖对方回应的不确定性——得到确定回应后激情反而消退。这警示"选我爱的人"若建立在迷恋之上，其情感基础本身易变；但转化后的陪伴之爱若能建立，深度不逊于任何开局。
